02. NÚCLEO ARQUITETURAL

Domínio Rico & Clean Architecture

Regras de negócio expressivas centralizadas no núcleo da aplicação, sem dependência de bibliotecas externas ou frameworks web.

🛡️ Entidade Produto com Proteção de Invariantes

src/domain/entities/produto.py
PYTHON 
@dataclass
class Produto:
    id: UUID
    nome: str
    preco: float
    categoria_id: UUID
    quantidade_estoque: int = 0
    imagem_url: str | None = None
    ativo: bool = True

    def __post_init__(self):
        if self.preco < 0:
            raise ValueError("O preço não pode ser negativo")
        if not self.nome or not self.nome.strip():
            raise ValueError("O nome do produto não pode ser vazio")

    def inativar(self):
        self.ativo = False

    def ativar(self):
        self.ativo = True

    def em_estoque(self) -> bool:
        return self.quantidade_estoque > 0

    def tem_oferta_local(self) -> bool:
        return self.ativo and self.em_estoque()

✓ Modelo Não-Anêmico: Validações e métodos expressivos incorporados diretamente na entidade.

📐 Separação Rigorosa das 4 Camadas

1. Domain (Núcleo Puro):

Entidades (Produto, Categoria) e interfaces abstratas (IProdutoRepository).

2. Application (Casos de Uso):

CriarProdutoUseCase valida se categoria existe antes de persistir, sem depender de framework.

3. Adapters & API (Entrada/Saída):

Controllers FastAPI, Pydantic DTOs e Repositórios concretos com SQLAlchemy.

4. Infrastructure (Drivers):

PostgreSQL 15, Alembic migrations, Uvicorn server e Docker Compose.

🔄 Gerenciamento e Versionamento com Alembic

alembic/versions/de4da57eb0d8_create_initial_tables.py
PYTHON 
def upgrade() -> None:
    op.create_table(
        'categorias',
        sa.Column('id', sa.UUID(), primary_key=True),
        sa.Column('nome', sa.String(), nullable=False)
    )
    op.create_table(
        'produtos',
        sa.Column('id', sa.UUID(), primary_key=True),
        sa.Column('categoria_id', sa.UUID(), sa.ForeignKey('categorias.id')),
        sa.Column('nome', sa.String(), nullable=False),
        sa.Column('preco', sa.Float(), nullable=False),
        sa.Column('quantidade_estoque', sa.Integer(), default=0),
        sa.Column('imagem_url', sa.String(), nullable=True),
        sa.Column('ativo', sa.Boolean(), default=True)
    )

def downgrade() -> None:
    op.drop_table('produtos')
    op.drop_table('categorias')
  • ✓ Rastreabilidade Total: Migrações aplicadas deterministicamente no deploy.
  • ✓ Rollbacks Seguros: Suporte nativo a reversão via downgrade().

05. SEGURANÇA & AUTENTICAÇÃO

Controle de Acesso, Autenticação e Criptografia

Proteção rigorosa das rotas de gestão administrativa com criptografia Bcrypt e tokens JWT assinados digitalmente.

🔑 Hashing Seguro e Emissão de Tokens

src/core/security.py
PYTHON 
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

def create_access_token(data: dict, expires_delta: Optional[timedelta] = None):
    to_encode = data.copy()
    if expires_delta:
        expire = datetime.utcnow() + expires_delta
    else:
        expire = datetime.utcnow() + timedelta(
            minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES
        )
    to_encode.update({"exp": expire})
    return jwt.encode(
        to_encode, 
        settings.SECRET_KEY, 
        algorithm=settings.ALGORITHM
    )
  • ✓ Bcrypt: Hashing com salt dinâmico imune a ataques de dicionário.
  • ✓ JWT HS256: Payload assinado digitalmente com tempo de expiração fixo.

🛡️ Guarda de Rotas via Dependências FastAPI

src/api/deps.py
PYTHON 
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="admin/login")

def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(
            token, 
            settings.SECRET_KEY, 
            algorithms=[settings.ALGORITHM]
        )
        username: str = payload.get("sub")
        if username != settings.ADMIN_USERNAME:
            raise HTTPException(
                status_code=401, 
                detail="Não foi possível validar as credenciais"
            )
        return username
    except JWTError:
        raise HTTPException(
            status_code=401, 
            detail="Token inválido ou expirado"
        )
Injeção Declarativa: Declarar current_user: str = Depends(get_current_user) protege o endpoint automaticamente.
