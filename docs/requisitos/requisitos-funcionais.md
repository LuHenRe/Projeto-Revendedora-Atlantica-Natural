# Requisitos Funcionais

## RF01 - Exibir produtos físicos na vitrine
O sistema deve exibir os produtos físicos ativos disponíveis para venda local na área pública da vitrine.

## RF02 - Validar região de atendimento antes do contato
O sistema deve bloquear ou desabilitar o botão de WhatsApp até que o usuário confirme a região permitida para atendimento.

## RF03 - Gerar mensagem de WhatsApp pré-formatada
Ao clicar no botão de contato, o sistema deve abrir o WhatsApp com uma mensagem previamente montada e direcionada ao produto ou categoria selecionada.

## RF04 - Exibir blocos de links externos
A página pública deve exibir blocos com links para categorias ou produtos da matriz, sem depender de persistência local dos itens afiliados.

## RF05 - Disponibilizar catálogo PDF
O sistema deve disponibilizar o catálogo geral em PDF ou em visualizador embutido, acessível pelos usuários da página pública.

## RF06 - Exibir CTA de captação de parceiros
A vitrine deve ter um bloco ou página dedicada para recrutamento de novas revendedoras, separada da jornada B2C.

## RF07 - Gerenciar produtos do estoque local
O administrador deve poder criar, editar e desativar produtos físicos do estoque local, com categoria, preço, imagem e status de disponibilidade.

## RF08 - Gerenciar categorias
O administrador deve poder criar, editar e excluir categorias de forma consistente, respeitando a regra de integridade de produtos ativos.

## RF09 - Controlar disponibilidade do produto
O sistema deve exibir apenas produtos ativos e disponíveis para venda local, ocultando itens indisponíveis ou fora de estoque.

## RF10 - Autenticar o administrador
O sistema deve realizar autenticação segura para acesso ao painel administrativo e às operações protegidas.

## RF11 - Exibir conteúdo editável da página
O administrador deve conseguir atualizar textos, imagens e blocos visuais da vitrine sem alteração no código fonte.

## RF12 - Acessar histórico de leads B2B
O sistema deve permitir ao administrador consultar os leads ou interesses de captação B2B.
